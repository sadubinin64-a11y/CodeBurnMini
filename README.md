# CodeBurn Mini

Неофициальный экспериментальный Android-виджет остатка лимитов Codex: 5 часов и неделя. Это не счётчик всех сообщений ChatGPT. Требуется Android 8 или новее и подходящий аккаунт.

## Скачать и установить
Скачайте **CodeBurnMini-0.5.apk** в разделе [Releases](https://github.com/sadubinin64-a11y/CodeBurnMini/releases/latest). SHA-256 приложен к выпуску.

Откройте приложение, нажмите «Войти через ChatGPT» и подтвердите показанный код на странице OpenAI. Каждый пользователь входит в собственный аккаунт. Затем добавьте виджет через меню рабочего стола.

**Переход с тестовой версии:** публичный APK подписан новым закрытым ключом выпуска и не устанавливается поверх старого тестового APK. Удаление старого приложения удалит его локальные данные, после установки потребуется новый вход. Переустановка для текущих пользователей необязательна.

При открытии приложения показатели обновляются автоматически. Есть ручное обновление. Фоновые проверки запрашиваются примерно раз в 30 минут; Android может их откладывать. При ошибке отображается последний снимок с сообщением ошибки.

## Конфиденциальность
Приложение обращается напрямую к auth.openai.com и chatgpt.com. Сервера разработчика, аналитики и рекламы в этих исходниках нет. Токены входа сохраняются на устройстве с AES-GCM и Android Keystore, резервное копирование отключено. Локально сохраняются также показатели лимитов, время и сообщение ошибки. Кнопка «Выйти и удалить данные» удаляет локально сохранённый вход и показатели; она не отзывает сессию на сервере.

В опубликованных исходниках и APK нет готового входа владельца проекта. Пароли, одноразовые коды и токены не следует размещать в Issues или присылать разработчику. Проверка исходников не является независимым аудитом безопасности.

## Ограничения
Используется внутренний интерфейс получения лимитов. Его доступность и совместимость могут измениться. Приложение не является продуктом OpenAI. Работа зависит от аккаунта и разрешённого входа по коду. Фоновая работа зависит от ограничений Android. Публичная сборка собрана из проверенных исходников; отдельная проверка именно этой подписи на физическом устройстве не проводилась.

## Сборка
Откройте проект в Android Studio. Настройки: SDK 35, AGP 8.9.2, Java 8 для исходников. Gradle wrapper в комплекте отсутствует.

Проверенный альтернативный путь с установленными build-tools 35.0.0 и платформой android-35:

```powershell
.\build.ps1 -JavaHome '<Android Studio>\jbr' -SdkRoot '<Android SDK>' -KeyStore '<закрытый ключ.p12>' -PasswordFile '<файл пароля>'
```

Скрипт запускает 17 проверок расчётов, собирает ресурсы, Java и DEX, выравнивает APK, подписывает предоставленным ключом, проверяет подпись и формирует SHA-256. Закрытые ключи и пароли храните вне репозитория. Новый ключ выпуска автоматически не создаётся.
